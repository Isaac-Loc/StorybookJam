## The project in one paragraph

StorybookJam is a multiplayer Mad-Libs picture book on DeepSpace. A signed-in
host picks a theme and each player gets their own secret blanks. Claude drafts
and moderates the six-page story, Fal illustrates it, and ElevenLabs narrates
it. The server enforces blank and draft privacy through record permissions.
Live: https://storybookjam.app.space

## Rules that matter most

- Do not commit, push or deploy unless the user asks. Deploy ships the local
  committed tree; pushing to GitHub does not deploy.
- Do not make paid calls (anthropic, fal, anything) without asking. Always set
  `maxCostUsd` on `fal/run-model`. Real spend: `npx deepspace app usage --json`.
- The repo is public: never commit secrets, `.dev.vars`, session files, test
  account passwords, or personal emails and IDs.
- Action tools run with RBAC off, so authorize the caller inside every action.
- The app owner is automatically `admin` and also plays: check every
  permission rule for that case.
- Never send raw player text to the image model; only moderated prompts.
- Keep the browser integration proxy deny-by-default
  (`src/server/integration-policy.ts`).
- On Windows, commit with `git commit -F <message-file>`; multi-line messages
  with double quotes break `-m` in PowerShell.

## Keep the docs current (required)

Any commit that changes behavior, limits or constants, collections or
permissions, actions, integrations or cost, workflows, or decisions must update
the matching section of docs/HANDOFF.md in the SAME commit (mapping in its
section 11). Re-verify every number before writing it, mark guesses as
unverified, update the "Resume here" snapshot and the session log at the end of
a working session, and never put secrets or personal details in docs.

## Before any commit

```bash
npm run type-check && npm run lint && npm run test:unit && npm run build
```

E2E (about 1.5 min, spends no credits): `npx deepspace test run tests/game.spec.ts`.
Repeated runs share the local room-creation limits. See "Testing" in
docs/HANDOFF.md.
